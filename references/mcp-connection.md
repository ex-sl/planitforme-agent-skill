# Подключение PlanItForMe к ИИ-агенту через MCP

Инструкция подходит для приложений и агентов, которые умеют запускать
локальный MCP-сервер через STDIO. Названия полей в интерфейсе могут отличаться,
но команда, аргумент и переменные остаются одинаковыми.

## 1. Выпустите именованный доступ

1. В PlanItForMe откройте **«Настройки» → «Ассистент»**.
2. В карточке **«Именованный доступ своего агента»** создайте доступ с понятным
   именем.
3. Сразу сохраните показанное значение: повторно оно не отображается.

Не помещайте это значение в диалог с агентом или в файлы репозитория.

## 2. Установите открытый соединитель

Для соединителя нужны Node.js 18 или новее и npm:

```bash
git clone https://github.com/ex-sl/planitforme-agent-skill.git ~/planitforme-agent
npm --prefix ~/planitforme-agent/mcp ci
cd ~/planitforme-agent && pwd
```

Последняя команда показывает абсолютный путь, который нужен в настройке MCP.

## 3. Добавьте MCP-сервер

Создайте локальный сервер со следующими параметрами:

- имя — `planitforme`;
- транспорт — `STDIO`;
- команда — `node`;
- аргумент — `<абсолютный путь>/mcp/server.mjs`;
- `BACKEND_URL=https://planitforme.ru`;
- `PLANIT_AGENT_CREDENTIAL=<показанное один раз значение>`.

Храните переменные в локальном защищённом хранилище настроек агента. Не
передавайте значение доступа как аргумент инструмента.

## 4. Добавьте правила работы

Если агент поддерживает навыки или подключаемые инструкции, добавьте
`SKILL.md` из репозитория. Если такого механизма нет, настройте те же правила:

1. сначала читать доступные действия через `planner_access`;
2. получать данные через `planner_read`;
3. готовить изменение через `planner_preview`;
4. применять его через `planner_apply` только после отдельного подтверждения
   показанного пользователю результата.

## 5. Проверьте подключение

Агент должен видеть четыре инструмента:

- `planner_access`;
- `planner_read`;
- `planner_preview`;
- `planner_apply`.

Попросите показать план на сегодня. Затем попросите подготовить небольшое
изменение без применения: агент должен показать предварительный результат и
дождаться подтверждения.

## Если подключение перестало работать

- Проверьте абсолютный путь к `mcp/server.mjs` и версию Node.js.
- Убедитесь, что локальный MCP-сервер включён в выбранном агенте.
- Если значение доступа утрачено или отозвано, выпустите новое в PlanItForMe.
