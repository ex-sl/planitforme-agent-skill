# Подключение PlanItForMe к Codex

Эта настройка выполняется один раз на каждом компьютере.

Codex — один из совместимых клиентов. Общие параметры для других агентов
приведены в [инструкции MCP](mcp-connection.md).

## 1. Выпустите именованный доступ

1. В PlanItForMe откройте **«Настройки» → «Ассистент»**.
2. В карточке **«Именованный доступ своего агента»** создайте доступ с
   понятным именем.
3. Сразу скопируйте показанное значение: повторно оно не отображается.

Не помещайте это значение в текст задачи Codex. Оно понадобится только в
локальной настройке сервера.

## 2. Подготовьте соединитель

Установите общедоступный навык через `$skill-installer` или клонируйте
<https://github.com/ex-sl/planitforme-agent-skill>. Соединитель входит в этот
же репозиторий. Для него нужны Node.js версии 18 или новее и npm. Проверьте их
командами `node --version` и `npm --version`, затем установите зависимости:

```bash
npm --prefix ~/.codex/skills/planitforme-agent/mcp ci
```

Получите фактический абсолютный путь к каталогу навыка:

```bash
cd ~/.codex/skills/planitforme-agent && pwd
```

Скопируйте выведенный путь. В настройке процесса нельзя полагаться на
сокращение `~`.

## 3. Добавьте сервер в Codex

В настольном приложении Codex:

1. Откройте **Settings → MCP servers**.
2. Нажмите **Add server**.
3. Выберите **STDIO**.
4. Укажите:
   - имя — `planitforme`;
   - команда — `node`;
   - аргумент — `<скопированный абсолютный путь>/mcp/server.mjs`;
   - `BACKEND_URL=https://planitforme.ru`;
   - `PLANIT_AGENT_CREDENTIAL=<показанное один раз значение>`.
5. Сохраните настройку и нажмите **Restart**.

## 4. Проверьте подключение

В новой задаче Codex введите `/mcp`. Сервер `planitforme` должен быть включён и
показывать четыре инструмента:

- `planner_access`;
- `planner_read`;
- `planner_preview`;
- `planner_apply`.

Затем попросите:

```text
Используй $planitforme-agent и покажи мой план на сегодня.
```

Если чтение работает, попросите подготовить небольшое изменение без
применения. Codex должен показать предварительный результат и дождаться вашего
подтверждения.

## Если подключение перестало работать

- Проверьте, что сервер `planitforme` включён в списке MCP.
- Перезапустите Codex после изменения настройки.
- Убедитесь, что именованный доступ не отозван.
- Если значение доступа утрачено, отзовите старый доступ в PlanItForMe и
  выпустите новый.
