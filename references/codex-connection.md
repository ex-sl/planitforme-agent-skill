# Подключение PlanItForMe к Codex

Это одноразовая настройка транспорта, а не дополнительная настройка
пространства PlanItForMe.

1. В PlanItForMe откройте **«Настройки» → «Ассистент»**, выпустите именованный
   доступ и сохраните показанное один раз значение.
2. Установите зависимости адаптера из клона PlanItForMe:

   ```bash
   npm --prefix <путь-к-planitforme>/mcp ci
   ```

3. В Codex добавьте локальный MCP-сервер типа STDIO:

   - имя: `planitforme`;
   - команда: `node`;
   - аргумент: `<путь-к-planitforme>/mcp/server.js`;
   - `BACKEND_URL=https://planitforme.ru`;
   - `PLANIT_AGENT_CREDENTIAL=<показанное один раз значение>`.

4. Перезапустите Codex. У подключённого сервера должны быть ровно четыре
   инструмента: `planner_access`, `planner_read`, `planner_preview`,
   `planner_apply`.
5. Начните задачу, например: `Используй $planitforme-agent и покажи мой план на
   сегодня`.

Не помещайте значение доступа в текст задачи, репозиторий, снимок экрана или
журнал. При утрате отзовите доступ в PlanItForMe и выпустите новый.
