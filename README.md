# PlanItForMe для ИИ-агентов

Открытый набор для подключения ИИ-агента к вашему пространству PlanItForMe:
соединитель MCP предоставляет четыре ограниченных инструмента, а `SKILL.md`
объясняет агенту безопасный порядок чтения, предварительного просмотра и
применения изменений.

Навык не содержит ваши данные доступа. Именованный доступ выпускается в
PlanItForMe и хранится только в локальной настройке выбранного агента.

## Что понадобится

- агент или приложение с поддержкой локальных MCP-серверов через STDIO;
- Node.js версии 18 или новее и npm для локального соединителя;
- именованный доступ из **«Настройки» → «Ассистент» → «Именованный доступ
  своего агента»**.

## Подключить к любому совместимому агенту

Репозиторий общедоступен. Склонируйте его и установите зависимости:

```bash
git clone https://github.com/ex-sl/planitforme-agent-skill.git ~/planitforme-agent
npm --prefix ~/planitforme-agent/mcp ci
cd ~/planitforme-agent && pwd
```

В настройках MCP вашего агента укажите:

- транспорт — `STDIO`;
- команда — `node`;
- аргумент — `<абсолютный путь>/mcp/server.mjs`;
- `BACKEND_URL=https://planitforme.ru`;
- `PLANIT_AGENT_CREDENTIAL=<именованный доступ>`.

Полный общий маршрут приведён в
[инструкции MCP](references/mcp-connection.md). Если агент умеет подключать
навыки или пользовательские инструкции из файла, добавьте `SKILL.md` из этого
репозитория.

## Установить в Codex

Проще всего попросить встроенный установщик Codex:

```text
Используй $skill-installer и установи навык из
https://github.com/ex-sl/planitforme-agent-skill
```

Для ручной установки выполните:

```bash
git clone https://github.com/ex-sl/planitforme-agent-skill.git \
  ~/.codex/skills/planitforme-agent
```

Codex обычно замечает новый навык автоматически. Если он не появился,
перезапустите Codex.

Подробности интерфейса Codex находятся в
[отдельном приложении к общей инструкции](references/codex-connection.md).

## Начать работу

Значение именованного доступа не вставляйте в текст задачи, репозиторий, снимок
экрана или журнал.

После настройки начните новую задачу, например:

```text
Используй $planitforme-agent и покажи мой план на сегодня.
```

Для изменения данных агент сначала должен показать предлагаемый результат и
только после вашего подтверждения применить его.

## Что умеет навык

- искать задачи, события и рутины;
- читать план, размещения, теги и историю;
- создавать и изменять дела;
- добавлять заметки внутрь задач без потери прежнего текста;
- готовить и применять изменения плана;
- возвращать доступные для отмены изменения.

Навык не управляет учётной записью, входом, экспортом, платежами или другими
подключениями. Отозвать его доступ можно в настройках PlanItForMe.
